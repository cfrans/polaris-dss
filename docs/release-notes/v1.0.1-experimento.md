# Polaris DSS v1.0.1-experimento

Frozen code for the data collection. It replaces `v1.0.0-experimento` before any official round;
no sample was collected with the previous tag. Everything in the
[v1.0.0-experimento notes](v1.0.0-experimento.md) applies, with this single correction:

- After removing or compressing a file, the executor reported the volume usage measured while it
  still held the source file open, so the freed blocks were not yet released (smoke rehearsal 18
  showed 97% used after removing 400 MiB). The usage is now read after the file is closed, after
  `sync`, waiting up to 3 s for the expected release; if the release is still not visible, the
  output says so instead of presenting the old value as current.

Identifiers: API 1.0.1-experimento, engine 0.3.0, knowledge base 1.0.2, migrations 001–010. The
script catalog hash changes because `apply_action.py` changed. The execution order in
`experiment/ordem_execucao.md` remains the one drawn on 2026-10-17.
