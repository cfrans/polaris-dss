Use o código gerado no servidor para criar o primeiro administrador.

Crie uma frase-senha de 15 a 128 caracteres. Guarde-a em um gerenciador de senhas.

Preparar o primeiro acesso

No terminal do servidor, após iniciar Docker e aplicar as migrações:

docker compose exec polaris-api python -m src.engine.setup_vault

O código só cria o primeiro administrador. Não há conta ou senha padrão.
