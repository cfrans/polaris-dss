Acesse por um túnel seguro

Este endereço usa HTTP fora do computador local. Para que sua senha não trafegue sem criptografia, abra o Polaris por HTTPS ou por um túnel SSH até o servidor.

  1. No seu computador, abra o túnel e mantenha o terminal aberto. Troque usuario pela sua conta no servidor.
    No seu computador
    ssh -N -L 8000:localhost:8000 usuario@servidor
  2. Depois, entre por http://localhost:8000/login.html.

Em um laboratório isolado, o administrador pode ligar o pareamento por HTTP no servidor. Entenda as opções de acesso ↗

Pareie este navegador

O servidor aceita acesso por HTTP na rede somente para navegadores pareados. Gere um código no terminal do servidor e informe-o abaixo.

No servidor Polaris
docker compose exec polaris-api python -m src.engine.pairing

O código vale uma vez e por poucos minutos.

HTTP não cifra a conexão. Senhas e sessão continuam visíveis na rede. Use o pareamento só em laboratório isolado. Saiba mais ↗

Navegador pareado por HTTP. A conexão não é cifrada; use apenas no laboratório isolado.

Minúsculas, números, ponto, hífen ou sublinhado.
Frase-senha de 15 a 128 caracteres. Guarde-a em um gerenciador de senhas.

Onde encontro o código de instalação?

No terminal do servidor, depois de iniciar o Docker e aplicar as migrações. O código aparece uma única vez, junto com o endereço para continuar pelo navegador.

No servidor Polaris
docker compose exec polaris-api python -m src.engine.setup_vault

O código só cria o primeiro administrador. Não há conta ou senha padrão. Perdeu o código? Gere outro acrescentando --rotate-access.
